# 女仆矿业 / Maid Mining

> 车万女仆（Touhou Little Maid）附属 · MC 1.21.1 · NeoForge
>
> 让车万女仆替你挖矿：圈定区域后自动分层挖掘或只找矿脉，挖满自己回站卸货、补食物，挖完自动烧矿。支持多女仆同层协作、战斗女仆守矿区。

---

## 这个 mod 解决什么

在大型科技整合包里，挖矿是纯粹重复劳动。这个 mod 让女仆自己完成：

**挖 → 装 → 运 → 存 → 烧** —— 全流程无人值守。

你只需要：

1. 用御币圈一块地
2. 把御币放进工作站
3. 走人

---

## 内容

### 物品

| 物品 | 用途 |
|---|---|
| **采矿御币** | 圈地、绑定工作站、分配区域、召回女仆 |
| **矿业工作站** | 女仆的家：存矿、补食物、烧矿、控制台（放御币 / 召回 / 停工 / 看状态） |
| **矿区工牌**（饰品） | 装备在女仆饰品栏，绑定工作站后自动接收工作区、上报状态 |

### 任务

新增「**采矿**」任务，两种模式：

| 模式 | 行为 |
|---|---|
| **清理区域** | 把区域里所有方块挖掉（保留箱子/熔炉等功能方块，刷怪笼会挖掉） |
| **找矿脉** | 只挖矿石，按价值排序（钻石 > 绿宝石 > 金 > 铁 > 铜 > 煤），挖到矿顺着矿脉连挖 |

### 自动化

| 情况 | 她的反应 |
|---|---|
| 背包塞满 | 回工作站 → 存进箱子 → 补食物 → 回去继续 |
| 站在工作站旁 | 每 2 秒自动卸货 + 补食物 |
| 区域挖完 | 回工作站烧矿（自动排除石头/沙/木头） |
| 烧完 | 停工站好，不再乱跑 |
| 挖到岩浆/着火 | 灭火、免伤（采矿期间） |
| 掉进水里 | 自动补氧气 |
| 挖穿了水源/岩浆源 | 拿背包里的方块堵上 |
| 上楼回站 | 走矿洞里留的台阶（一级一级走，不用寻路硬解） |
| 台阶那一级是沙砾/沙子 | 挖掉后用圆石补一块（沙砾会塌，不能当台阶） |
| 台阶走不通 | 台阶两端允许垫高 1~2 格；再不行 60 秒后传送 |
| 走丢 / 卡住 | 20 秒无进展 → 传送到最近待挖点 / 工作站 / 区域顶部 |
| 站在里面动不了 | 把自己挖出来 |

### 多女仆

给多只女仆圈**同一片区域** → 她们**一起挖同一层**（不会各挖一条导致一边深一边高），
靠"方块认领"避免抢同一格：谁先认领谁挖，5 秒没动自动释放。

### 楼梯（回站通道）

挖矿时会**贴着离工作站最近的那面墙**留一条台阶：

```
双跑回转楼梯：两条跑道各 2 格宽，跑到头掉头，一直折到区域底部
每跑 8 级自动选（区域太窄会降级，实在不行就不留）
台阶坐标记在女仆身上，重启也不会被当成普通方块挖掉
```

### 战斗女仆守矿区

给战斗任务的女仆圈一片区域 → 她被锁在区域内巡逻打架（战斗 AI 用她自己的）。

## 上手三步

### ① 圈地

| 操作 | 作用 |
|---|---|
| **Shift + 右键方块** | 定起点 |
| **右键方块** | 定对角终点 |

> 只决定 X/Z 范围；挖多深、往上多少在女仆界面里调。

### ② 放工作站 + 绑定

放下**矿业工作站**，手持御币右键它。

### ③ 分配

- 方式一：手持御币**右键女仆**
- 方式二：**御币放进工作站** + 女仆装备工牌（自动派活）

---

## 设置界面

右键女仆 → 任务列表选「采矿」→ 点设置：

```
向下深度    40    挖多深（0 = 只挖最上面一层，用来平整地块）
向上高度     0    往上挖多少（削平小山包/树）
火把        开    沿途插不插火把（不消耗）
模式      清理    清理区域 / 找矿脉
矿种      全部    找矿模式下只挖：全部 / 铁以上 / 稀有（金·钻石·绿宝石）
```

## 前置

装之前请确认版本**落在下面的区间里**，否则游戏会直接提示前置不满足（这是故意的，省得你进去踩坑）：

| 前置 | 版本区间 | 说明 |
|---|---|---|
| **Minecraft** | `1.21.1` | 只支持这一个版本 |
| **NeoForge** | `21.1.0` ～ `21.1.x` | 21.2 及以上不支持 |
| **车万女仆** | `1.5.0` ～ `1.5.x` | 1.6 及以上不支持 |

**不需要**：智能女仆（Promaid）、万法皆通，或任何其它附属。

安装顺序：先装 NeoForge → 再放车万女仆 → 最后放本 mod（`maidmining-*.jar`）。

## 已知限制

- 找矿模式搜索半径 32 格、上下 ±20 格，再远的矿找不到（性能取舍）
- 只封「源头」的水/岩浆，流动的仍会漫过来
- 台阶补铺要消耗背包里的实心方块（挖矿产的圆石就够用）
- 区域太窄（沿墙方向 < 6 格或垂直方向 < 4 格）时不留台阶
- 更早版本挖出来的旧台阶不在保护名单里，会被当普通方块挖掉
